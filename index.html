Execution model

Y-program instructions manage rounded rectangles, text generators and palette updates. X-program instructions resolve paint spans and one-bit text masks into 64 palette layers. This reference simulator is scanline-based; hardware scheduling and ownership-frontier timing are not yet cycle-accurate.
