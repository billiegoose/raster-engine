The execution contract

X-program: a sorted linked list of START/STOP events. Each event changes a layer reference count; the highest active layer wins.

Y-program: transforms that list for the next row, reusing stable nodes and applying insertions, deletions and coordinate changes. Palette writes happen at row boundaries.

Prototype boundary: the simulator currently computes each complete scanline and its next-row transform in sequence. The moving ownership frontier, BRAM contention, read-ahead FIFO and cycle-accurate concurrent scheduling are not implemented yet.
